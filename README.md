GasPol adalah platform aplikasi web berbasis pemetaan dan informasi layanan publik yang dirancang untuk mempermudah masyarakat khususnya pengendara kendaraan bermotor dalam mengakses informasi seputar SPBU Pertamina secara terpadu, akurat, dan real-time.
Fungsi Utama AplikasiPelacakan Lokasi SPBU Terdekat:
- Menampilkan daftar dan rute SPBU Pertamina yang berada di sekitar posisi pengguna untuk menghemat waktu pencarian saat di perjalanan.   
- Monitoring Ketersediaan & Harga BBM:Memungkinkan pengendara untuk mengecek status ketersediaan stok bahan bakar (seperti Pertalite, Solar, Pertamax, Pertamax Green, Pertamax Turbo, Dexlite, dan Pertamina Dex) serta memantau update harga resmi terkini sebelum mendatangi SPBU.
